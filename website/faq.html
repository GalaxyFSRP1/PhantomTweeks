Frequently asked questions

Honest answers, including the ones that are less flattering than the marketing would like.

Safety
Will Phantom Tweeks get me banned by anti-cheat?

Phantom Tweeks only changes documented Windows settings through the standard registry and power-configuration APIs. It does not inject into game processes, hook anything, modify game files, or interact with anti-cheat software beyond detecting that it is running so Phantom Shield can protect it.

That said, no third party can make guarantees on behalf of an anti-cheat vendor. Use with competitive titles at your own discretion — as with any system utility.

Can it break my PC?

Every change is recorded with its exact prior value before anything is written, and RESTORE EVERYTHING reverts all of them. Security software, Windows Update and CPU mitigations are on a permanent deny-list enforced in code, not just hidden in the UI.

The design rule is explicit: given a choice between marginal performance and possible instability, Phantom Tweeks chooses stability.

Will it close Discord, Steam or my game?

No — never, in any mode. Phantom Shield is a hard deny-list wired into every code path that could touch a process. There is no automatic termination feature to accidentally trigger. If an application is consuming resources, Phantom Tweeks reports it and leaves the decision to you.

Does Expert Mode let me bypass the safety system?

No. Expert Mode exposes more information — registry values, power configuration, process telemetry, adapter properties — but it grants no additional destructive capability. Built-in Shield protections cannot be removed by any user at any privilege level.

Performance
How much FPS will I gain?

Possibly none, and Phantom Tweeks will tell you so. On a well-configured modern PC the honest answer is usually that there is very little left on the table, and the comparison report will say "No measurable improvement was detected."

Where gains do appear they are most often in 1% lows — frame-time consistency — rather than average FPS. That is the difference you actually feel.

Why does it say "No change recommended"?

Because the tweak would not help your specific hardware. Assigning a high-performance GPU preference does nothing on a single-GPU system. Disabling desktop animations will not change in-game FPS on a 32 GB machine. Reporting that honestly is the product working correctly.

Why can't it show my GPU utilisation or temperature?

Live GPU telemetry requires vendor tooling — nvidia-smi ships with the NVIDIA driver, and AMD/Intel expose data differently. Similarly, most desktop CPUs need a kernel-level driver to report package temperature, and Phantom Tweeks will not install a kernel driver on your machine to fill in a number.

Where a value cannot be measured it reads "n/a". It is never estimated.

Why do I need PresentMon for frame times?

Because there is no honest way to measure a game's frame times from outside without the presentation data Windows exposes through PresentMon. Rather than simulate plausible-looking FPS numbers, Phantom Tweeks reads real captures from Intel's free PresentMon, or imports a CapFrameX/PresentMon CSV you already have.

Network
Will it lower my ping?

No, and any tool promising otherwise is selling you something. Latency is dominated by physical distance to the game server and your ISP's routing. Phantom Tweeks measures your connection so you can find what is actually wrong — packet loss on your own Wi-Fi, jitter from a saturated link, or an upstream routing problem.

Isn't changing DNS supposed to improve gaming?

DNS resolves names to addresses. Once you are connected to a game server, your DNS provider is not involved in gameplay traffic at all. A faster resolver speeds up name lookups; it will not fix packet loss, jitter or ping. The Network Lab benchmarks DNS and labels it accordingly.

Why does it test my router separately?

Because it isolates the fault. Loss and jitter to your own gateway point at Wi-Fi interference, a bad cable or the router. A clean local hop with a dirty internet hop points upstream at your ISP. Testing only one of them tells you nothing about which.

Product
Is it really free?

Yes. The core suite is free and stays free. Premium is planned but not implemented — there is no payment code in the application and no fake locked buttons.

Do I need administrator rights?

Most features work as a standard user, including all monitoring, diagnostics, benchmarking and network testing. A few machine-wide settings such as GPU scheduling require elevation, and Phantom Tweeks tells you which ones instead of demanding blanket administrator rights at launch.

What data does it collect?

None. There is no telemetry endpoint compiled into the build. Hardware information, game information and crash logs stay on your PC. Sharing a crash log is a manual choice you make.

What happens to my backups if I uninstall?

They are deliberately kept, so you can reinstall and still restore your previous configuration. If you want to revert everything, run RESTORE EVERYTHING before uninstalling.

Does it work on Windows 7, 8 or Linux?

No. Phantom Tweeks targets Windows 10 (build 17763+) and Windows 11. On any other platform it starts in analysis-only mode: monitoring and network diagnostics work, but every mutating operation politely refuses rather than guessing.
