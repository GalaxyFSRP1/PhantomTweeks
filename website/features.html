◈ Features

Everything in Phantom Tweeks

Forty-plus capabilities across safety, analysis, hardware, network, optimization and workflow — all built on the same rule: measure it, explain it, back it up, and make it reversible.

Safety

Nothing else matters if the tool breaks your PC.

🛡

Phantom Shield

A hard deny-list wired into every process-touching code path. Games, launchers, voice chat, capture software, anti-cheat, GPU services, input software and essential Windows processes can never be killed, suspended, reprioritised, re-affinitised or injected into.

＋

Custom Protected Apps

Add your own executables to the protection list with wildcard support. Built-in protections cannot be removed by anyone, including Expert Mode.

💾

Backup Vault

Every change records its exact prior value before anything is written. Where no value existed, restore removes the key rather than guessing a default.

↺

One-Click Restore

A permanently visible RESTORE EVERYTHING button that reverts only what Phantom Tweeks recorded. Settings you changed yourself are never touched.

⚠

Safe Mode & Recovery

Advanced changes verify the backup, warn you, and require multi-step confirmation. Recovery instructions are provided if something goes wrong.

🔒

Security Deny-List

Defender, Firewall, Windows Update, security mitigations and anti-cheat services are permanently off-limits at the API level — not just hidden in the UI.

Analysis

Understand the machine before changing it.

◉

Live Dashboard

CPU/GPU utilisation, clocks and temperatures, VRAM, RAM, disk activity, network throughput, latency, jitter and packet loss. Unavailable sensors read "n/a".

◎

Performance Score

Eight transparent sub-scores — Gaming, CPU, GPU, Memory, Storage, Network, Background Load and System Configuration — each showing its formula and measured inputs.

⌕

Phantom Scan

Ten-section sweep across hardware, drivers, Windows config, graphics, startup, background load, storage, network, gaming config and protected processes.

⚖

Bottleneck Detection

Samples utilisation over a window and tells you whether you are GPU-bound, CPU-bound, memory-limited, network-limited or genuinely balanced.

▤

Frame-Time Analyzer

Average, 1% low and 0.1% low frame times, pacing score, stutter counting and a frame-time graph, from real PresentMon or CapFrameX captures.

⌁

Input Latency Analysis

Reviews refresh rate, V-Sync state, VRR/G-SYNC/FreeSync availability, frame pacing and GPU saturation — with recommendations, not magic-millisecond claims.

Hardware

Vendor-aware, never assumed.

▮

CPU Analysis

Model, physical and logical cores, architecture, live and maximum clocks, per-core utilisation, temperature where a sensor is readable, and active power plan.

▰

GPU Analysis

NVIDIA, AMD and Intel detection with model, driver version, VRAM, temperature, clock, utilisation and power draw. NVIDIA settings are never suggested on AMD hardware.

⚙

Driver Center

GPU, chipset, network and audio driver versions and dates with staleness detection and official vendor links. Phantom Tweeks never installs a driver for you.

▣

Storage Lab

HDD, SATA SSD and NVMe detection with capacity, free space, health status, temperature and read/write activity, plus safe cleanup candidates.

✚

System Health Center

At-a-glance CPU, GPU, RAM, Storage, Network, Drivers and Windows status — every warning carries the reason behind it.

▦

Background Analyzer

Merges processes by application and ranks them by CPU and memory. Heavy consumers are reported; nothing is ever closed for you.

Network

Measurement, not marketing.

⇅

Network Lab

Ping, jitter and packet-loss tests against your gateway and the internet separately, so a local Wi-Fi problem is never blamed on your ISP.

◇

DNS Benchmark

Compares resolver response times across major providers — clearly labelled as name-lookup speed, which is not the same as game-server ping.

⇢

Route Diagnostics

Traceroute-based hop analysis for identifying where latency is introduced along the path.

∿

Stability Test

Sustained probing over time to catch the intermittent drops and spikes a four-packet ping will always miss.

📈

Network History

Stores results locally and graphs daily averages so you can prove to your ISP that Thursday really was worse.

⬒

Connection Detection

Identifies Ethernet vs Wi-Fi and factors it into every recommendation, because the cable usually beats the tweak.

Optimization

Explained, rated, reversible.

ⓘ

Change Explanations

Every optimization has an info button showing purpose, expected effect, risk level, supported Windows versions and whether it is reversible.

◆

Confidence Ratings

HIGH, MEDIUM, LOW or NOT RECOMMENDED — with the reasoning. Only high-confidence, low-risk, reversible items are ever eligible for automatic mode.

⏻

Startup Manager

Startup entries with impact estimate, publisher, path and status. Critical Windows components and protected apps cannot be disabled. All changes reversible.

⚡

Windows Optimization

Game Mode, graphics preferences, GPU scheduling, power configuration, Game DVR, visual effects and storage headroom — analysed against your actual system.

📊

Before/After Comparison

Side-by-side FPS, 1% lows, frame time, pacing and network deltas, with changes under 2% correctly labelled as measurement noise.

⟲

Automatic Rollback

If a post-change benchmark shows a meaningful regression, Phantom Tweeks says so and offers to restore the previous configuration immediately.

Workflow

Built around how you actually play.

🎮

◈

Game Profiles

Competitive, Balanced, Quality, Streaming and Creator presets covering graphics, FPS targets, frame pacing, display, network and background guidance.

⏱

Gaming Mode

Detects your game, extends Shield across its whole process tree, records session performance and monitors network stability. It closes nothing.

🎥

Streaming & Creator Modes

Tuned around OBS, microphones, webcams and capture. Encoder headroom is protected instead of being sacrificed for a few extra frames.

📸

Configuration Snapshots

⌘

Command-Line Interface

scan, optimize, benchmark, network-test, restore, hardware, health, drivers, storage, expert and more. Writing commands require explicit confirmation.
