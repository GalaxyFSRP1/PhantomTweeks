Support & troubleshooting

Recovery instructions, diagnostics and common fixes. If Phantom Tweeks ever leaves your system in a state you dislike, there is always a way back.

Something went wrong after an optimization?

Open Phantom Tweeks and press RESTORE EVERYTHING. If Windows will not boot normally, start in Safe Mode and run:
PhantomTweeks.exe restore --all --yes
This reverts every change Phantom Tweeks recorded, and nothing else.

Recovery

Recovery plan

1

Use one-click restore

The RESTORE EVERYTHING button is always visible in the sidebar and on the History page. It replays every recorded backup newest-first.

2

Restore a single run

History & Restore lists every optimization run with its date, title, change count and backup id. Select one and restore only that.

3

Use the CLI from Safe Mode

If the GUI will not start, PhantomTweeks.exe restore --all --yes works from any command prompt, including Safe Mode with Networking.

4

Reboot if prompted

Some settings — notably GPU scheduling — only take effect, and only revert, after a restart.

5

Inspect the log

Every action is logged to %LOCALAPPDATA%\PhantomTweeks\logs\phantomtweeks.log, including changes Phantom Shield blocked and why.

Common issues

Troubleshooting

GPU temperature or utilisation shows "n/a"

Live GPU telemetry needs vendor tooling. On NVIDIA, nvidia-smi ships with the driver — make sure the driver is properly installed. AMD and Intel expose data through their own software.

Phantom Tweeks deliberately shows "n/a" rather than an estimate. A fabricated temperature is worse than no temperature.

CPU temperature is unavailable

Most desktop motherboards only expose package temperature through a kernel-level driver. Phantom Tweeks will not install a kernel driver on your machine just to display a number, so it reports the ACPI thermal zone where available and "n/a" otherwise.

Frame-time capture says no source is available

Install Intel PresentMon (free) and place PresentMon.exe on your PATH or in %LOCALAPPDATA%\PhantomTweeks\tools\. Alternatively, import an existing CapFrameX or PresentMon CSV from the Frame-Time page.

An optimization is greyed out or says it requires administrator rights

Machine-wide settings such as GPU scheduling write to HKEY_LOCAL_MACHINE. Close Phantom Tweeks, right-click it and choose "Run as administrator", then apply. Everything else works fine as a standard user.

Network tests report 100% packet loss to everything

Your firewall or network is blocking ICMP echo. This is common on corporate and some VPN connections and does not mean your connection is broken — it means ping-based measurement cannot work there.

My game was not detected

Detection matches running processes against installed-library paths. Games installed outside a recognised launcher, on a network drive, or launched through a wrapper may not match. Gaming Mode still protects launchers, voice chat and anti-cheat regardless.

The application crashed

A crash log is written to %LOCALAPPDATA%\PhantomTweeks\logs\crash\. It contains the stack trace and basic system information — no personal files, no credentials — and it is never uploaded automatically. Sharing it is entirely your choice.

Diagnostics

Gathering information

These commands print everything needed to understand a problem, and none of it leaves your machine unless you send it.

Command Prompt
# version and platform support
PhantomTweeks.exe version

# full hardware inventory and live telemetry
PhantomTweeks.exe hardware

# system health with explanations
PhantomTweeks.exe health

# what Phantom Shield is protecting right now
PhantomTweeks.exe shield

# detailed technical dump (enable Expert Mode first)
PhantomTweeks.exe config --set expert_mode=true --yes
PhantomTweeks.exe expert

# list every change ever applied
PhantomTweeks.exe restore

Log files

%LOCALAPPDATA%\PhantomTweeks\logs\ — rotating application log plus crash reports.

💾

Backups

%LOCALAPPDATA%\PhantomTweeks\backups\ — one readable JSON file per optimization run.

🗑

Complete removal

Run RESTORE EVERYTHING, uninstall, then delete %LOCALAPPDATA%\PhantomTweeks\. Nothing else is left anywhere on the system.
