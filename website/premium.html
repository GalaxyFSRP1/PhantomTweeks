Architecture

Built now, enabled later

The account and licensing seams already exist in the codebase so Premium can be added without redesigning the application — and so the security decisions are locked in before money is ever involved.

🔑

Delegated authentication

Passwords are never stored or handled by the client. Authentication delegates to an OAuth2/OIDC provider and the client holds only a short-lived token.

🔐

OS credential storage

Tokens live in Windows Credential Manager, never in a plain-text configuration file next to the executable.

🖥

Device management

Licence-to-device binding and revocation are handled server-side, so a stolen licence file is worthless on its own.

☁

Cloud profiles

Profile sync will be explicitly opt-in per profile. Nothing leaves your PC because you happened to sign in.

✓

Server-side validation

Licence checks happen over HTTPS with certificate validation on. The client never self-certifies its own entitlement.

∅

Inert by default

PREMIUM_AVAILABLE = False — the flag is off in the shipped build and is_premium() always returns false.

How licensing works

Signed keys, verified on your machine

Cryptographically signed

Every key carries an Ed25519 signature. Phantom Tweeks verifies it against a public key built into the app, so a key cannot be forged or edited — change one character and it stops validating.

Works offline

Verification happens on your PC. If our licensing server is down or you are offline, your key keeps working. We will never lock a paying customer out because of an outage on our side.

No payment code in the app

Phantom Tweeks contains no payment processing and will never ask for card details inside the application. Keys are issued out-of-band.

Your email is never in the key

If you supply an email at purchase it is stored only as a one-way hash inside the key. The key itself contains no readable personal data.

Being straight with you: signature checking stops people inventing keys. It cannot stop a determined person patching the program to skip the check — no software can. We would rather say that than pretend otherwise.
