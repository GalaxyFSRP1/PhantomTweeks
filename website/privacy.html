🔒 Privacy

Privacy Policy

The short version: Phantom Tweeks collects nothing, transmits nothing, and sells nothing. Here is the long version.

Last updated: 5 September 2026 · Applies to Phantom Tweeks 0.2.0

Summary

Phantom Tweeks runs entirely on your computer. There is no analytics endpoint compiled into the application, no account requirement, and no background network activity other than the diagnostic tests you explicitly run and the optional update check.

What we collect

Nothing. Phantom Tweeks does not collect, transmit, sell, rent or share any personal information. There is no user account, no device fingerprint sent anywhere, and no hidden analytics.

What stays on your device

The application reads and stores the following locally, in a single folder you control:

  • Hardware information — CPU, GPU, memory, storage and driver details, used to generate recommendations.
  • Game information — installed and running games detected from launcher manifests, used for profile matching.
  • Performance data — benchmark captures, frame-time statistics and session samples.
  • Network results — latency, jitter and packet-loss history from tests you run.
  • Configuration and backups — your settings and the prior values of every change made.
  • Logs and crash reports — application activity and stack traces.

All of it lives in %LOCALAPPDATA%\PhantomTweeks (or beside the executable in the portable build). Deleting that folder removes every trace of your data.

Network activity

Phantom Tweeks makes network requests in exactly two circumstances:

  • Diagnostic tests you start. The Network Lab sends ICMP echo requests to your gateway, to public IP addresses such as 1.1.1.1, and to DNS resolvers you have selected. These carry no personal data — they are ping packets.
  • Update checks. If enabled, the application requests a version manifest over HTTPS. The request contains no identifying information beyond what any HTTPS client necessarily reveals, and it can be disabled in Settings → Updates.

Crash reports

If the application crashes, a report is written to your local disk containing the stack trace, the application version and basic system information such as OS build and architecture. It contains no personal files, no credentials and no game data.

Crash reports are never uploaded automatically. If you choose to share one to help diagnose a problem, that is an action you take deliberately.

Optional sharing settings

Three settings exist in Settings → Privacy: telemetry, hardware information sharing and game information sharing. All three default to off, and there is currently no endpoint for them to send data to. They exist so that if such a feature is ever added, it is opt-in by construction rather than opt-out by apology.

Third parties

Phantom Tweeks bundles no third-party analytics, advertising or tracking SDKs. It does not integrate with social platforms. Optional frame-time capture uses Intel PresentMon only if you install it yourself; that is a local process, not a service.

Children

Phantom Tweeks is a system utility not directed at children and collects no information from anyone, including children.

Future changes

If a future version introduces any data collection, it will be opt-in, disclosed on this page before release, and clearly presented in the application. Silent introduction of telemetry would contradict the reason this product exists.

Your rights

Because no data is collected, there is nothing to request, correct or delete on our side. Your data is on your disk, under your control, in a plain folder you can inspect and remove at any time.

Contact

Privacy questions can be raised through the Support page.
