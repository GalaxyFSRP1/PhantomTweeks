🎮 Games

Game detection & profiles

Phantom Tweeks reads your installed libraries, identifies the running game and its whole process tree, and applies a profile built for how you actually play. Detection is entirely read-only.

Game files are never modified

Phantom Tweeks reads launcher manifests and process metadata. It does not patch game executables, alter configuration files, inject into game processes, or interact with anti-cheat software in any way. Anti-cheat is detected purely so Phantom Shield can protect it.

Auto game profile

Detected, protected, recommended — never silently changed.

When a supported game launches, Phantom Shield immediately extends across its entire process tree. A matching profile is selected and its recommendations are prepared — but nothing is applied unless you explicitly enabled automatic optimization, and even then only high-confidence, low-risk, reversible items qualify.

  • Shield extends to the game, its children and its launcher
  • Anti-cheat detected and protected, never modified
  • Session performance and network stability recorded
  • Significant changes always require your approval

Profiles

Five presets, plus your own

Every profile covers graphics, FPS targets, frame pacing, Windows settings, display, network and background guidance — and keeps its own benchmark history.

Esports titles

Competitive

Lower shadows, reflections and effects first. Cap FPS just below refresh rate so the GPU never fully saturates, keeping input latency low and consistent. Confirm maximum refresh rate and enable VRR.

General play

Balanced

Match the in-game preset to your resolution and adjust only the two heaviest settings. Enable VRR for smooth frame delivery.

Single-player

Quality

Prioritise texture and lighting quality, then cap FPS at your refresh rate to keep frame times even.

Gaming + OBS

Streaming

Leave GPU headroom for the encoder by capping in-game FPS. OBS, Discord and audio software stay protected and running.

Recording & editing

Creator

Optimises for encoder and editing throughput rather than peak game FPS. Capture applications are never deprioritised.

Configuration snapshots

Save named snapshots — Competitive Gaming, Streaming, Everyday, Maximum Performance, Default Windows — and switch between them. A snapshot can only ever contain settings Phantom Tweeks actually manages, so restoring one can never clobber something you configured elsewhere.
